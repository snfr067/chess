# 台灣暗棋：個人棋路學習 v2

這是 4×8 台灣暗棋 PWA。AI 使用凍結的戰術基礎網路，加上只學單一玩家決策的個人適配器；每局完成或中斷後更新個人模型。

## 直接執行

此專案是靜態網站，請以 HTTP 伺服器開啟，避免直接使用 `file://`：

```bash
python -m http.server 4173
```

瀏覽 `http://localhost:4173/`。首次載入後，Service Worker 會快取應用程式、TensorFlow.js 與基礎模型。

## v2 學習規則

- 一般由玩家走的合法行動：正樣本。
- AI 提案經玩家按下「同意這一步」：正樣本。
- 「只改這一步」：玩家替代行動為正樣本；被拒提案加入成對負標籤。
- 「接下來由您下」：該回合後續每個玩家示範行動皆為正樣本。
- 暗棋翻出結果只更新公開狀態，不改寫玩家標籤。
- 系統強制結束回合不建立停止標籤；玩家主動按下結束回合才記錄停止。
- AI 未經玩家同意而自動執行的行動不加入個人資料。

連吃採逐段決策。每次成功食用後，模型讀取該段結果，再評估 `stop` 與同一顆棋的下一批合法目標。

## 模型與資料保存

瀏覽器 IndexedDB 資料庫名稱：`taiwan-dark-chess-learning-v2`，版本 1。此資料庫與舊版 `taiwan-dark-chess-learning` 完全隔離，舊模型或舊棋譜異常不會阻塞新版 AI；新版會從乾淨的個人模型開始累積。

- `games`：棋局與完成／中斷狀態
- `turns`：完整回合與連吃事件
- `decisions`：候選、玩家標籤、凍結基礎嵌入與訓練欄位
- `models`：個人模型 A/B 槽與現用指標
- `metrics`：訓練前評估結果

設定頁可匯出完整模型與棋譜 JSON、重新匯入，或切回上一個 A/B 模型槽。清除網站資料、改用不同瀏覽器使用者資料或不同來源網址，仍會影響 IndexedDB；請定期匯出備份。

## 模型組成

- 棋盤：4×8×25 公開資訊通道
- 暗棋信念：己方／對方共 14 種剩餘棋分布
- 棋盤編碼器：32 通道卷積與 3 個殘差區塊
- 目前回合：32 維 GRU，最多 16 個事件
- 近期歷史：32 維 GRU，最多 32 個事件
- 候選：117 維，含 24 維固定成本戰術後果
- 候選頭：128 → 64 → 分數
- 個人適配器：16 維風格向量、64→16→64 殘差適配器、rank-8 適配器與個人輸出偏置

基礎模型檔案為 `base-model.json` 與 `base-model.weights.bin`；建置工具為 `tools/train-base.mjs`。玩家裝置只更新個人適配器。

## 每局更新

每局結束時，程式先使用更新前模型計算 Top-1／Top-3，再用本局、全部糾正資料與最多 8,192 筆分層回放訓練 3 個 epoch。優化器為 Adam，學習率 `0.0005`，批次 32。模型先寫入非現用槽，交易成功後才切換指標。
